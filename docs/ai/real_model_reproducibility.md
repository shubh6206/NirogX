## 3. Runtime Provenance Verification

Every execution returns an explicit runtime provenance tag to ensure simulated numbers are never conflated with real GPU outputs:

- `real_medgemma_colab`: Output generated by official `google/medgemma-1.5-4b-it` running on Google Colab GPU over remote FastAPI tunnel.
- `real_medgemma_local_gpu`: Output generated on local workstation NVIDIA CUDA GPU.
- `real_medgemma_adapter_gpu`: Output generated by fine-tuned LoRA adapter on GPU.
- `simulated_local_engine`: Deterministic simulated baseline engine (used exclusively for local unit tests; **strictly prohibited when `MEDGEMMA_EVALUATION_MODE=true`**).
